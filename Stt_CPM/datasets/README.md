# Dataset assets

The refactored code expects the following renamed assets:

- `chikusei/chikusei_source_patches_128bands_7x7.pkl`
- `houston/houston_hyperspectral_image.mat`
- `houston/houston_ground_truth.mat`
- `indian_pines/indian_pines_hyperspectral_image.mat`
- `indian_pines/indian_pines_ground_truth.mat`
- `salinas/salinas_hyperspectral_image.mat`
- `salinas/salinas_ground_truth.mat`
- `university_of_pavia/university_of_pavia_hyperspectral_image.mat`
- `university_of_pavia/university_of_pavia_ground_truth.mat`

The binary dataset files were not part of the uploaded Python sources, so this package
contains the expected directories and paths but does not fabricate dataset binaries.
